# v0.8.0：把 Windows 安装包压到 10MB 以内

> 一句话介绍：AI-SSH-Pro 是一次轻量化的桌面版更新——Windows 安装包缩小到 10MB 以内，功能一个没少，名字也更干净了。

![AI-SSH-Pro 主界面](01-cover-ai-terminal.png)

官网：http://121.196.45.81/ai-ssh-pro/

---

## 这次更新做了什么

v0.8.0 没有堆新功能，主要解决一个实际问题：**下载和升级太慢**。

- **体积**：Windows 安装包从原来的大包压到 **10MB 以内**（NSIS 约 3–4MB）。下载更快，升级也更快。
- **名称**：产品对外名称统一为 **AI-SSH-Pro**，安装包和快捷方式不再带框架名。
- **能力**：多会话 SSH、AI 确认后执行、SFTP、ProxyJump、运维工具箱等常用功能全部保留。

安装包的准确文件名和体积，以官网页面为准。

---

## 为什么体积值得单独说一次

对桌面工具来说，10MB 和 80MB 的差别不只是下载时间。小安装包意味着：

- 升级几乎无感，适合频繁迭代；
- 分发给同事或团队时，一个链接、几十秒就能装好；
- 在带宽受限的服务器上也更友好。

为了让体积降下来，这次把桌面运行时换成了更轻的方案，同时保持了原来的功能范围。

---

## 快速开始

1. 打开官网，下载 Windows 安装包（文件名与体积以官网页面为准）。
2. 安装后可以先连内置的**演示主机**体验，数据全部模拟，不会连真实服务器。
3. 在 **设置 → AI** 填入你自己的模型 Provider（任意 OpenAI 兼容接口，如 DashScope、DeepSeek），就可以用了。
