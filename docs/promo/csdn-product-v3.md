# AI-SSH-Pro：给 SSH 客户端配一个「会先问你」的 AI 助手

> 一句话介绍：AI-SSH-Pro 是一款在本地运行的多会话 SSH 桌面客户端，内置 Cursor 风格的 AI 运维助手。AI 负责观察终端、给出下一步方案，是否执行、怎么执行由你决定——默认「执行前确认」。

## 一、适合谁

- **运维 / SRE**：同时盯好几台机器，希望一个窗口看全状态，AI 帮忙把排查步骤理清楚。
- **后端开发**：经常上服务器查日志、重启服务，需要「AI 给命令，我先看再执行」。
- **小团队负责人**：想引入 AI，又要求生产机器的执行权限可控、有记录。
- **从 Xshell / FinalShell 迁移的用户**：熟悉多标签和会话树，不想重新学一套操作。

## 二、核心能力

### 1. 打开就是运维首页

在线主机数、需要处理的告警和无法连接的主机放在最上面；每台主机一张卡片，显示 CPU、内存、磁盘的最近一次采样和更新时间；卡片上可以直接进入终端、SFTP 或监控。

![运维首页与主机指标](02-ops-home.png)

### 2. 多会话 SSH：标签、分屏、跳板与转发

- 多标签、分屏、会话分组，支持搜索和按标签过滤。
- 多级 ProxyJump、本地 / 远程端口转发、主机密钥 TOFU（首次确认指纹，变更时告警）。
- 可导入 OpenSSH `config`、Xshell `.xsh`、PuTTY，最近连接一键重连。
- 生产主机在标签页顶部带醒目提示条，时刻提醒当前环境。

![终端与生产环境提示](03-terminal-production.png)

### 3. AI 面板常驻终端右侧

排障时不用切窗口：提问是浅色气泡，回复是干净的正文；建议命令合并成一个紧凑代码块，带 **复制 / 执行** 和低 / 中 / 高风险标签；每条回复下面显示耗时，可一键复制。输入区一行完成：选模型、选执行策略、附带终端输出、发送。

![AI 面板中的命令块](04-ai-panel-command.png)

### 4. 三档执行策略：AI 不替你拍板

| 策略 | 行为 |
|---|---|
| 仅建议 | AI 只给命令，不碰终端 |
| 执行前确认（默认） | 变更类命令需要你点确认才执行 |
| 自动执行 | 按策略直接执行，高风险操作仍可要求确认 |

策略可以全局设置、按主机设置，也可以在单个标签页里临时调整；界面上始终显示当前**实际生效**的那一档。

![三档 AI 执行策略设置](05-ai-policy-settings.png)

### 5. 主机保护：只读主机硬拒绝

每台主机可以标记为普通 / 生产 / 只读：

- **只读**：主进程直接拒绝 AI 写入终端，即使你在界面上点了同意也不生效。
- **生产**：保留你选的策略，但顶部常驻提醒，避免看错机器。

![主机安全卡片](06-host-safety-card.png)

### 6. 对话、历史与审计都有落点

每个终端标签页一段对话，按主机归档，切换标签页不会串台；历史对话按主机分组随时找回；AI 执行过的动作记入审计日志，可以按类型、结果筛选。

![AI 历史对话](07-ai-history.png)

### 7. SFTP、批量执行与运维工具箱

- SFTP 双栏浏览与传输，拖拽上传，传输队列可见。
- 批量执行：勾选已连接的会话，一条命令发到所有机器，各自显示自己的结果。
- 服务器工具箱：进程、systemd 服务、监听端口、日志查看，每个动作先问再做，可选 sudo。

![SFTP 双栏传输](08-sftp-dual.png)

### 8. 主机档案 + MCP，AI 和外部工具共享同一份资料

主机档案存在本地磁盘（默认 `~/.ai-ssh-pro/inventory`），应用内 AI 与独立的 stdio MCP 服务读同一份文件，可以接进 Cursor、Claude Desktop 等支持 MCP 的工具。

## 四、安全设计

- **确认再执行**：默认策略下，AI 给出的变更命令必须由你点确认。
- **敏感字段不进 AI**：密码、私钥、口令由你在本地填写，不会被 AI 代填，也不会发给模型。
- **凭据只在本机**：会话密码、私钥口令、API Key 使用系统安全存储（如 Windows DPAPI）加密，不随仓库分发。
- **本地优先、无账号、无遥测**：数据都在本机；可选的加密云同步（私有 Gist / WebDAV）默认关闭，数据在本机用 scrypt + AES-256-GCM 加密后才上传。
- **可审计**：每次执行都留记录，事后可以回溯。

## 五、下载与安装

1. 打开官网或 Releases 页面，下载 Windows 安装包（当前 10MB 以内，文件名与体积以 Release 页面为准）。
2. 安装后可以直接连内置的**演示主机**体验，数据全部模拟，不会连到真实服务器。
3. 在 **设置 → AI** 填入你自己的模型 Provider（任意 OpenAI 兼容接口，如 DashScope、DeepSeek），再选执行策略。
4. 需要的话，把 `~/.ssh/config` 导入进来，或给主机建一份本地档案。

## 六、最后

AI 助手在 SSH 场景里最危险的地方，是它可以替你在生产机器上敲回车。所以 AI-SSH-Pro 的设计取向很明确：**AI 负责观察和计划，执行权留在人手里**，只读主机上连「同意」都不算数。
