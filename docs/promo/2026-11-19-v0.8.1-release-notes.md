## AI-SSH-Pro v0.8.1

AI 对话与稳定性补丁 / AI chat and stability patch. Released 2026-11-19 (CST).

### 亮点 / Highlights
- **多会话并行对话**：每个终端标签页独立对话，停止只中断当前这一轮，切换标签页不再串台。
  Parallel AI conversations: one conversation per terminal tab; Stop cancels only the current turn; switching tabs no longer mixes streams.
- **修复**：Tauri 测连与 Electron 对齐；回复文本空值防护；AI 每轮对话结束落盘；快速上手按钮同行；设置页与终端表单对齐；窄列表与标签序号可读性。
  Fixes: Tauri provider-test parity, empty-reply guard, AI chat persistence, onboarding layout, settings alignment, narrow-list readability.
- **官网**：推广稿、更新端点与迁移文档统一指向阿里云自建站。
  Promo copy, updater endpoint and migration docs point to the self-hosted site.
